# NOIR SALON — Video Assets (source)

This folder is the requested canonical home for the landing media.

The Vite app serves static media from `/public`, so the running build reads the
files from **`/public/videos/`**. Keep an identical `/public/videos/` copy in sync,
or import directly from here if you prefer bundling.

Files expected:

- `intro.mp4` — Splash background video
- `hero.mp4` — Homepage Hero background video

See `/public/videos/README.md` for details.
