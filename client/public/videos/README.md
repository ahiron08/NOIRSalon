# Video Assets

## Intro Video
- **File**: `intro.mp4`
- **Used in**: Splash screen before website loads
- **Specifications**:
  - Duration: 4-6 seconds recommended
  - Resolution: 1920x1080 (Full HD) or higher
  - Format: MP4 with H.264 encoding
  - File size: Under 10MB for fast loading
  - Aspect ratio: 16:9 (landscape)
- **To replace**: Simply overwrite `intro.mp4` with your video file

## Hero Video
- **File**: `hero.mp4`
- **Used in**: Background video on homepage
- **Specifications**:
  - Duration: Any (loops automatically)
  - Resolution: 1920x1080 recommended
  - Format: MP4 with H.264 encoding
  - File size: Under 20MB
  - Aspect ratio: 16:9 (landscape)

## Optimization Tips
1. Use [HandBrake](https://handbrake.fr) or [CloudConvert](https://cloudconvert.com) to compress videos
2. For web: H.264 codec, 30fps, 1920x1080 resolution
3. Target file size: Intro <10MB, Hero <20MB
4. Add a poster image for slow connections (optional)

## Video Sources
- Free stock videos: [Pexels](https://www.pexels.com/videos/), [Pixabay](https://pixabay.com/videos/)
- Your own footage: Shoot with smartphone, then compress with HandBrake
